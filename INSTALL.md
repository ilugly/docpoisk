# Установка ДокПоиск на MacBook — пошагово

Инструкция для тех, кто ни разу не работал с Терминалом. Команды можно копировать прямо отсюда.

**Что понадобится**
- MacBook с macOS 11 (Big Sur) или новее;
- интернет на время установки (скачается около 3–6 ГБ, это 10–30 минут);
- примерно 10 ГБ свободного места на диске.

После установки интернет больше не нужен.

---

## Сначала определите, какой у вас случай

| Ситуация | Что делать |
|---|---|
| Ставлю впервые | [Шаг А: первая установка](#шаг-а-первая-установка) |
| Уже ставила раньше командой `git clone …` | [Шаг Б: обновление](#шаг-б-обновление-если-уже-ставили) |
| Уже ставила раньше, скачав ZIP-архив | [Шаг В: обновление ZIP-версии](#шаг-в-если-раньше-скачивали-zip) |
| Не помню | Выполните в Терминале `ls ~/docpoisk`. Если появился список файлов, это **Б**. Если «No such file or directory», делайте **А** |

> **Одна команда на любой случай** (первая установка или обновление любой версии):
> ```bash
> if [ -d ~/docpoisk/.git ]; then cd ~/docpoisk && git fetch origin && git reset --hard origin/main; else git clone https://github.com/ilugly/docpoisk.git ~/docpoisk && cd ~/docpoisk; fi && bash install.sh
> ```

> **Как открыть Терминал:** нажмите `⌘ Cmd + Пробел`, напечатайте «Терминал» (или «Terminal») и нажмите Enter.
> Команду вставляйте через `⌘ Cmd + V` и запускайте клавишей Enter. Пока команда работает, по экрану бежит текст. Дождитесь, когда снова появится строка с `%` в конце.

## Шаг А: первая установка

**1.** Откройте Терминал, вставьте команду и нажмите Enter:

```bash
git clone https://github.com/ilugly/docpoisk.git ~/docpoisk
```

Если выскочит окно «Для команды git нужны инструменты разработчика», нажмите **Установить** и дождитесь окончания (5–10 минут), затем вставьте команду ещё раз.

**2.** Запустите установку:

```bash
cd ~/docpoisk && bash install.sh
```

Скрипт сам поставит всё нужное и скачает нейросети. Что может случиться по ходу:
- **Запросит пароль от Mac.** Введите его и нажмите Enter. Символы при вводе не отображаются, это нормально.
- **Откроется окно Ollama** («Welcome to Ollama»). Его можно просто закрыть, программа продолжит работать в фоне. Иконка ламы в строке меню вверху означает, что Ollama запущена.
- **Долго висит на `pulling …` с процентами.** Это скачиваются модели, ждите.

**3.** В конце появится «Готово!», и откроется окно **ДокПоиск**. Всё, установка закончена.

Дальше приложение запускается как любое другое: `⌘ Cmd + Пробел` → «ДокПоиск» → Enter. Или через Launchpad.

## Шаг Б: обновление (если уже ставили)

Команду `git clone` повторять **не надо**, она выдаст ошибку «already exists». Вставьте в Терминал эту команду:

```bash
cd ~/docpoisk && git fetch origin && git reset --hard origin/main && bash install.sh
```

Она подходит для **любой** старой версии, включая самую первую, где ещё не было файла `update.sh`. Команда скачивает свежую версию программы и запускает установщик. Тот закроет старое приложение, если оно открыто, и откроет обновлённое.

**Загруженные документы, база и настройки сохраняются**, загружать документы заново не придётся. Команда меняет только папку программы `~/docpoisk`, а данные лежат отдельно, в `~/DocPoisk`.

> В новых версиях то же самое делает короткая команда `cd ~/docpoisk && bash update.sh`. Если она пишет `No such file or directory`, значит, у вас версия до её появления: используйте длинную команду выше.

## Шаг В: если раньше скачивали ZIP

1. Закройте ДокПоиск, если он открыт: `⌘ Cmd + Q`.
2. Удалите старую папку проекта, например `docpoisk-main` в «Загрузках». Ваши документы и база лежат не там, а в `~/DocPoisk`, они не пострадают.
3. Дальше сделайте [Шаг А](#шаг-а-первая-установка). Так в следующий раз сможете обновляться одной командой.

## Как пользоваться

1. **Перетащите документы** в левую панель: PDF, Word, Excel, PowerPoint, TXT и другие. Под каждым файлом виден прогресс, дождитесь «готово».
2. **Задайте вопрос** в строке внизу и нажмите Enter.
3. В ответе есть номера `[1]`, `[2]`. Если на них нажать, откроется кусок документа, откуда взят ответ.
4. Чтобы искать только в некоторых документах, **отметьте их галочками** слева.
5. Чтобы загрузить сразу много файлов, положите их в папку `DocPoisk/inbox` (в Finder: `⌘ Cmd + Shift + H` → папка `DocPoisk` → `inbox`) и нажмите в приложении «из папки inbox».

Первый ответ после запуска может идти дольше обычного: нейросеть загружается в память.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Внизу слева красным «Ollama не запущена» | Откройте Ollama через Launchpad (иконка ламы) и перезапустите ДокПоиск |
| «Не хватает моделей» | Нажмите там же «Скачать модели» (нужен интернет) или снова выполните `cd ~/docpoisk && bash install.sh` |
| Документ загрузился с ошибкой «В файле не найден текст» | Это скан (картинка). Его нужно распознать в программе с OCR (ABBYY FineReader, Adobe Acrobat) и загрузить распознанный PDF |
| «Формат .doc не поддерживается» | Откройте файл в Word или Pages и сохраните как .docx |
| Окно приложения не открывается | В Терминале выполните `cd ~/docpoisk && bash run.sh --browser`, и интерфейс откроется в браузере |
| `command not found: git` | Выполните `xcode-select --install`, нажмите «Установить», потом повторите шаг |
| `Permission denied` | Запускайте через `bash install.sh`, а не `./install.sh` |
| `update.sh: No such file or directory` | У вас первая версия, в ней ещё не было этого файла. Обновитесь длинной командой из [Шага Б](#шаг-б-обновление-если-уже-ставили) |
| `destination path '…docpoisk' already exists` | Программа уже стоит, `git clone` повторять не нужно. Делайте [Шаг Б](#шаг-б-обновление-если-уже-ставили) |
| `not a git repository` | Папка скачана ZIP-архивом. Делайте [Шаг В](#шаг-в-если-раньше-скачивали-zip) |
| `cd: no such file or directory: …/docpoisk` | Программа лежит в другой папке (например, `docpoisk-main` в «Загрузках»). Делайте [Шаг В](#шаг-в-если-раньше-скачивали-zip) |
| `Your local changes … would be overwritten` | Вы обновлялись через `git pull`. Используйте команду из [Шага Б](#шаг-б-обновление-если-уже-ставили), она этой ошибки не даёт |
| Ответы слишком медленные | Закройте тяжёлые программы (браузер с кучей вкладок, Telegram). На 8 ГБ памяти это особенно заметно |
| Что-то другое | Пришлите файл `~/DocPoisk/app.log` и последние строки из Терминала |

## Где что лежит

- `~/docpoisk` — программа. Её можно удалять и ставить заново, данные от этого не пострадают.
- `~/DocPoisk` — **ваши данные**: база, копии документов, настройки (`settings.env`), лог.
- `~/Applications/ДокПоиск.app` — ярлык приложения.

## Как удалить полностью

```bash
rm -rf ~/docpoisk ~/Applications/ДокПоиск.app
```

Чтобы удалить ещё и все загруженные документы и базу, добавьте `rm -rf ~/DocPoisk`. Ollama удаляется как обычная программа: перетащите её из «Программ» в Корзину.
